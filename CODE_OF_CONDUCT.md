# Code of conduct

We welcome contributors of all backgrounds and experience levels. Be respectful,
constructive and patient. Critique ideas and code rather than people, and accept
corrections in good faith. Help keep discussions useful and accessible.

Harassment, threats, discriminatory language, unwanted sexual attention,
deliberate disruption and publishing someone else's private information are
not acceptable. These rules apply to repository issues, pull requests, reviews
and other project spaces.

Maintainers may edit, remove or lock content and restrict participation when
needed to protect contributors. Moderation should be proportionate to the
behavior, consider its impact and avoid unnecessary disclosure of private data.

For abuse or harassment, use GitHub's **Report content / Report abuse** controls
to make a private platform report. Non-sensitive concerns about project conduct
can be raised with the maintainer in a project issue. Do not publish personal
details when reporting. Security vulnerabilities have their own private channel
in [SECURITY.md](SECURITY.md).
