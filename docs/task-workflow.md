# Статусы задач и ответственность

Статус задачи показывает состояние результата. Состояние запуска показывает,
что сейчас делает исполнитель. Завершение запуска само по себе не означает Done.
`linear_issues.get.work_status`, `linear_child_tasks.work_status` и статус задачи
из личного ассистента используют одну модель.

| Статус Linear | Значение | Ответственный |
| --- | --- | --- |
| Backlog | Идея или работа, еще не взятая в исполнение | Назначенный владелец; отсутствие назначения видно явно |
| Todo | Задача подготовлена к запуску | Назначенный исполнитель |
| In Progress | Идет работа, исправления или координация активных подзадач | Исполнитель задачи |
| Blocked | Нужен ответ, восстановление интеграции или устранение ошибки | Исполнитель сохраняется; отдельно указан тот, от кого нужен следующий шаг |
| In Review | Результат сохранен и передан на проверку | Автор остается исполнителем; проверяет Квай-Гон или владелец |
| Done | Результат проверен и принят | Квай-Гон принимает обычные задачи, владелец принимает важные |
| Canceled / Duplicate | Работа отменена или объединена с другой задачей | Не устанавливаются из-за сетевой ошибки |

## Исполнители

- Родительская агентская задача делегирована Квай-Гону, подзадача – конкретному специалисту.
- В Linear агент указан в `delegate`. Поле `assignee` относится к человеку.
  Создание агентской задачи не назначает владельца человеческим исполнителем.
- Запрос ответа у владельца не меняет исполнителя. `waiting_on` и `next_action`
  объясняют, кто должен сделать следующий шаг.
- Смена исполнителя пользователем сохраняется. Автоматическая синхронизация
  не переписывает назначения и не запускает оставшийся без исполнителя бэклог.

## Переходы

1. При запуске делегированной задачи: Todo/Backlog → In Progress.
2. Нужен ответ или выполнение остановилось: In Progress → Blocked.
3. Причина автоматической блокировки устранена: Blocked → In Progress.
   Ручная блокировка не снимается автоматически.
4. Автор вызывает `review` с результатом и проверкой: In Progress → In Review.
   Нельзя подменить это прямой сменой статуса.
5. Нужны правки: In Review → In Progress до редактирования материала.
6. Приемка: In Review → Done. Специалист не принимает собственную работу.
   Важные, публичные, финансовые, стратегические и другие зарезервированные
   задачи оставляются владельцу. Прямой переход агента в Done запрещен.

Принятые и отмененные задачи не открываются автоматически и их материалы не
перезаписываются агентом. Новая работа требует отдельного решения владельца.

## Родитель и подзадачи

- Пока специалисты работают, родитель остается In Progress и отвечает Квай-Гон.
- Если координатор ждет заблокированную подзадачу, родитель получает Blocked.
- Родитель можно передать в Review, когда все подзадачи переданы на проверку
  или завершены, а активные исполнения закончили передачу результатов.
- Новое исполнение подзадачи возвращает родителя из Review в работу.
  Уже принятый родитель автоматически не открывается.
- Перед Done все подзадачи должны быть приняты, отменены или объединены.
- Завершившийся запуск без передачи результата на проверку не выдает готовность:
  незакрытая задача получает Blocked, чтобы координатор проверил сохраненную работу.

## Сбой и восстановление

Временный сбой Linear сохраняет запуск, результаты и связи между задачами.
Следующая попытка запланирована в базе и переживает перезапуск адаптера.
При исчерпании лимита запросов все обращения одного приложения ждут разрешенного
времени. Это не отказ в правах и не потеря документа.

Отдельные попытки публикации и передачи результата используют прежние идентификаторы.
Восстановление связи не создает новый запуск модели. Если само выполнение упало,
сохраняется частичный результат, задача блокируется и требуется осознанное продолжение.

Статус в Linear синхронизируется при изменении состояния исполнения. При недоступном
API отображение может отставать; следующий запрос повторяется автоматически.
Приемка всегда повторно проверяет актуальные данные Linear. Ручные изменения
внешних клиентов не являются доказательством выполненной работы.
