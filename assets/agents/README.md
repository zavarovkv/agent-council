# Аватарки команды

Текущие выбранные владельцем портреты сохранены из подключённых профилей Linear
без перегенерации. Исходные промпты этих изображений неизвестны.

| Файл | Агент | Референс |
| --- | --- | --- |
| `qui-gon.jpg` | Квай-Гон Джинн | Зелёный портрет координатора |
| `dexter.jpg` | Декстер Джеттстер | Синий портрет исследователя |
| `lando.jpg` | Лэндо Калриссиан | Тёплый портрет специалиста по продвижению |
| `padme.png` | Падме Амидала | Фиолетовый портрет редактора; промпт в `padme.md` |

Это образцы общей рисованной стилистики для следующих агентов. Правила генерации,
кропов и сохранения промптов описаны в [agent-profiles.md](../../docs/agent-profiles.md).
Для нового портрета сохранять рядом квадратный оригинал и `<id>.md` с промптом
и перечнем использованных референсов. Оригиналы будущих генераций — PNG или WebP.
